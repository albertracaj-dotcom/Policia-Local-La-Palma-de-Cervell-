# Policia Local La Palma de Cervelló · VMP / VTC

Aplicació web pròpia de suport per a consultes, guies de comprovació i registre local de controls relacionats amb VMP i VTC.

## Publicació amb GitHub Pages
1. Obre **Settings → Pages**.
2. A **Build and deployment**, selecciona **Deploy from a branch**.
3. Tria la branca `main` i la carpeta `/(root)`.
4. Desa els canvis. GitHub publicarà l'aplicació a l'adreça Pages del repositori.

## Funcions incloses
- Mòduls separats per VMP i VTC.
- Guia pràctica orientativa.
- Enllaços a fonts oficials.
- Formulari per registrar controls.
- Historial local, cerca, eliminació i exportació CSV.
- Manifest i service worker bàsic per a instal·lació i ús offline parcial.

## Privacitat i limitacions
- Els registres s'emmagatzemen al `localStorage` del navegador/dispositiu; no hi ha servidor ni sincronització.
- Les fotografies només es previsualitzen; no es desen.
- No es consulta automàticament cap base de dades, REAT ni registre oficial.
- No és una eina de validació jurídica ni substitueix les normes consolidades, instruccions policials o ordenances vigents.
- Evita introduir dades personals innecessàries. El dispositiu i el navegador han d'estar protegits.

## Desenvolupament
L'aplicació és una implementació original en HTML, CSS i JavaScript sense dependències externes. El contingut normatiu i els procediments s'han de revisar i actualitzar abans de l'ús operatiu.
